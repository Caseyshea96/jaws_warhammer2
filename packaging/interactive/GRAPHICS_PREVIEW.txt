WARHAMMER II NVDA ACCESSIBILITY PREVIEW

Speaks the game's front-end menus through NVDA, the way NVDA reads any
program: name, role, state, then position (for example "New Campaign,
button, 1 of 22"). The screen name is spoken when you arrive on a screen.

START
1. Start NVDA, then run "Start Pilot.cmd" (or the desktop shortcut).
2. Launch the game through Steam and TW Mod Manager with jaws_access enabled.
3. Install warhammer2-quiet-mode-0.1.0.nvda-addon once (from the App folder)
   and restart NVDA, so NVDA stays quiet while the game has focus.

KEYS (in the game's menus, while the game window has focus)
  Down arrow / Up arrow   next / previous item
  Tab                     next item (Shift+Tab is Steam's overlay)
  Home / End              first / last item
  Enter or Space          activate the item (press once)
  A letter                next item starting with that letter
  Escape                  the game's own Back key
  F2 / F3 / F4            also next / previous / activate

The companion window takes these keys only while the game is focused and on
a menu screen; everywhere else they belong to the game and other programs.

WHAT WORKS
- Main menu: New Campaign and Graphics open.
- Select Campaign: Continue opens Select Lord.
- Select Lord: every item is read; choosing a lord works and is confirmed
  ("Teclis is now selected."). The screen re-reads itself when the lord or a
  difficulty changes.
- Graphics and Advanced graphics are read; their settings cannot be changed.
- Other buttons say "Not supported yet." Start Campaign is not enabled.

OPTIONS
- confirm-activations.flag in %LOCALAPPDATA%\JawsWarhammer2 makes every
  action need two presses within four seconds.

DEVELOPMENT
Automation.ps1 drives the same handlers for testing (lease-gated, disabled by
default); see docs/FRONTEND_AUTOMATION.md in the source repository.
