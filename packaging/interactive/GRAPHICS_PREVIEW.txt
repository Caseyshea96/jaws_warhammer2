WARHAMMER II NVDA ACCESSIBILITY PROTOTYPE

An early prototype that lets Total War: WARHAMMER II be played with NVDA
and the keyboard: menus, starting a campaign, reading the campaign screen,
managing settlements (build, recruit) and ending turns. Moving armies and
battles are NOT supported yet. Your feedback on how things should be
controlled is the main goal of this test.

Items are spoken the way NVDA reads any program: name, role, value, states,
then position, for example "Recruit Lord, button, 53 of 106".

------------------------------------------------------------------------
INSTALL (once)
1. Close the game. Extract the whole ZIP to a folder.
2. Run Install.cmd. It finds the Steam game folder (or asks for the folder
   containing Warhammer2.exe), copies jaws_access.pack into the game's data
   folder and the helper into %LOCALAPPDATA%\JawsWarhammer2\App. It makes a
   desktop shortcut "Warhammer JAWS Pilot".
3. Install warhammer2-quiet-mode-0.1.0.nvda-addon (in the App folder) into
   NVDA and restart NVDA. It keeps NVDA quiet while the game has focus, so
   only the mod's speech is heard.

EACH TIME YOU PLAY
1. Start NVDA and Steam (signed in).
2. Run the desktop shortcut "Warhammer NVDA Pilot" (or Start Pilot.cmd).
   This small helper passes the mod's speech to NVDA and handles the keys
   below; keep it running. It tests speech, then starts the game itself
   with only the accessibility mod: no TW Mod Manager window. You hear
   "Starting Warhammer with the accessibility mod." Other mods are not
   loaded in this mode. The intro movies play first, about two minutes
   (Escape skips them); the menu is not read until they end.
   When the main menu is ready you hear
   "Warhammer accessibility ready. Arrow keys move, Enter activates."
   If Steam was not running, the game opens through Steam instead: in TW
   Mod Manager make sure jaws_access is ticked, then press Play.

------------------------------------------------------------------------
KEYS IN MENUS
  Down / Up arrow     next / previous item
  Tab                 next item (Shift+Tab is Steam's overlay)
  Home / End          first / last item
  Enter or Space      activate (one press)
  A letter            next item starting with that letter
  Escape              the game's own Back key
  F2 / F3 / F4        also next / previous / activate

STARTING A CAMPAIGN
  Continue Campaign (main menu) loads your latest save. Load Campaign is
  not supported yet.
  Main menu: Campaigns / New Campaign  ->  Select Campaign: Continue  ->
  Select Lord: choose a lord with Enter ("Teclis is now selected.").
  "Enable campaign introduction, check box": we suggest unchecking it with
  Enter for now. The tutorial locks End Turn and several buttons until its
  objectives (which need army movement) are done.
  "Start Campaign" asks first: press Enter twice.
  The map then loads and an intro flyover plays (about a minute).

------------------------------------------------------------------------
ON THE CAMPAIGN MAP
When the map is ready you hear "Campaign map, N items." and, if a panel is
open, its title (for example "How They Play, heading"). Items are read in
screen order: a panel's title, its text, then its buttons.

  Shift+F2            HUD reading ON / OFF. It starts ON: the keys below
                      read the screen ("Reading HUD."). OFF: arrows move the
                      camera as normal ("Map controls.").
  Down / Up, Home/End, letters    move between items (HUD reading on)
  Enter               press the current button, tab, list item or building
  Shift+F3            read the screen again. If the reader ever goes
                      silent (keys do nothing), press Shift+F3; please
                      tell us when that happens and what you had just done.
  F2 / F3 / F4        next / previous / activate, even with HUD reading off

When a panel opens or closes you hear "Screen updated." and the reader moves
to the new panel's title or first new item. Advisor and notification text is
spoken when it changes ("Advisor: ...").

Actions that cannot be undone ask first: End Turn, Quit/Exit/Load, Abandon,
Recruit and Build ("...? Press Enter again to confirm."). Moving away
cancels.

THINGS TO TRY (in a new campaign)
1. Opening panels: "How They Play" and "Mission Issued!" appear first. Press
   A to reach "Accept, button" and Enter. C reaches "Close advice".
2. Provinces: press P until "Provinces, tab", Enter. Each province is one
   item: "Straits of Lothern, list item, 520, Contested province, Public
   Order: Neutral, Building upgrades available". Enter selects it and opens
   its settlement panel.
3. Settlement panel: each settlement name is a heading, followed by its
   buildings: "Lothern (Elven Hamlet), button, Lothern, Building upgrades
   available", "Construction slot, button, Lothern, locked". G reaches the
   province figures: "Growth, 0/600 (+20)", "Turns until surplus point, 30",
   "Population Surplus, 1", "Tax Province, check box, checked" (read only for
   now), "Income, 520", "Public order, 0 (-1), Neutral".
4. Build: Enter on a building gives its upgrades as a short list ("Upgrades
   for Lothern (Elven Hamlet), 5 options."). Arrow to an upgrade
   ("Lothern (Elven Village), button, Population surplus cost 1"), press
   Enter twice to build. Afterwards the slot reads "under construction,
   3 turns left". "Close upgrades" leaves the list.
5. Recruit a lord: in the settlement panel press R until "Recruit Lord,
   button", Enter. Lord types are tabs (Legendary Lords, Prince, Princess);
   each candidate is one item with cost and upkeep, and says why if you
   cannot afford them. The selected lord's stats follow ("Armour, 80,
   Shielded", "Leadership, 80"). Enter on a candidate selects it; then R to
   "Recruit, button" and Enter twice. (Moving the new army is not supported
   yet.)
6. Your armies: press L until "Lords & Heroes, tab", Enter. Each lord is one
   item: "Tyrion, list item, Legendary Lord, 116 soldiers, faction leader,
   rank 1". Enter selects him (the camera goes to him) and reads his army:
   "Tyrion, heading", then each unit, for example "Spearmen, list item,
   Spear Infantry, strength 30", and "Unit count, 7/20". Moving him is not
   supported yet.
7. Notifications: S reaches "Skip, button" to skip the current notification.
8. End turn: E reaches "End turn, button". Enter twice. If it says "End turn
   is unavailable", read its description: usually advice or a notification
   needs dismissing first. Ending a turn makes the game autosave.

NOT SUPPORTED YET
Moving armies or agents, battles, diplomacy screens beyond reading, changing
game settings, and co-op. Many panels are read but their buttons may say
"Not supported yet." Reading order inside some panels is still rough.

------------------------------------------------------------------------
FEEDBACK
Most useful: what you tried, what you expected to hear or press, and what
felt slow or confusing. Ideas for better keys are very welcome.
If something breaks, note what you pressed and what was said last, and send
these files from %LOCALAPPDATA%\JawsWarhammer2 :
  bridge.jsonl, native-ui-graphics-preview.log,
  native-ui-campaign-discovery.jsonl (if present), companion.log
They contain game screen text only (no passwords).

REMOVE
Close the game and the helper, then run Uninstall.cmd. Saves and other
mods are kept.

OPTIONS
confirm-activations.flag in %LOCALAPPDATA%\JawsWarhammer2 makes every menu
action need two presses within four seconds.
