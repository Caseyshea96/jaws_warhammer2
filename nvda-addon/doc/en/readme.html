Warhammer II Quiet Mode 0.1.0

This experimental NVDA add-on enables NVDA sleep mode only while Total War: WARHAMMER II is focused. It suppresses the game's broken native accessibility events while allowing the separate Warhammer accessibility companion to provide speech.

The add-on defines no keyboard gestures, sends no game input, and contains no mouse code.

Removal

Open NVDA's Add-on Store or Add-on Manager, select Warhammer II Quiet Mode, choose Remove, and restart NVDA.
