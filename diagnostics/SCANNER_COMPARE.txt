WARHAMMER II NVDA READ-ONLY SCANNER COMPARISON 0.5.3

This investigation build uses the proven 0.4.3 bounded frontend scanner.
After the baseline capture, it logs the 0.5.2 native reader on the same root
and first child, with and without the preview's protected action wrapper.
A final direct root sample checks whether later reads remain consistent.
These comparisons test hypotheses; they do not establish a root cause alone.

F2/F3 browse only. F4 is disabled. There are no clicks or game commands.
The initial F2 captures once per launch, then navigation uses captured entries.

Close game and companion. Uninstall the current preview, then run Install.cmd
from this package. Keep NVDA Quiet Mode enabled. Launch through the normal
Mod Manager with only jaws_access enabled.

At the main menu, TAP F2 ONCE, then wait for speech to finish. If controls are
announced, F2/F3 can browse. Send bridge.jsonl and native-ui-scanner-compare.log
from %LOCALAPPDATA%\JawsWarhammer2. This build does not enable speech tracing;
any existing speech-trace.jsonl may belong to the earlier preview.
The old native-ui-diagnostic.log is preserved and is not the new capture.

The unchanged 0.4.3-nvda-diagnostic ZIP remains available as a rollback.
